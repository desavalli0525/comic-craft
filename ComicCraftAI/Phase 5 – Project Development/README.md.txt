# Phase 5 – Project Development

## Development Environment

The project was developed using Visual Studio Code.

## Project Structure

The project contains the following major components:

- app
- ai
- services
- templates
- main.py
- routes.py
- requirements.txt
- .env

## Frontend Development

The frontend provides the interface for entering story prompts and
viewing the generated comic output.

## Backend Development

The backend handles user requests and connects the application with
the AI services.

## AI Integration

AI services are integrated to generate creative story content and
comic-related visuals.

## Environment Configuration

Environment variables are used to store configuration details and
API credentials securely.

## Output

The application generates comic content based on the user's story
prompt.
