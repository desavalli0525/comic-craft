# Phase 6 – Project Testing

## Testing Objective

The objective of testing is to verify that all major features of
ComicCraftAI work correctly.

## Test Cases

| Test Case | Input | Expected Result |
|---|---|---|
| 1 | Valid story prompt | Comic should be generated |
| 2 | Empty prompt | Validation message should appear |
| 3 | Short prompt | System should process the prompt |
| 4 | Long prompt | System should process the input correctly |
| 5 | Invalid input | Appropriate error should be displayed |
| 6 | AI service request | Generated content should be returned |
| 7 | Image generation | Comic visual should be generated |
| 8 | Final output | Comic should be displayed correctly |

## Testing Result

The application was tested with different inputs to verify the
functionality of the system.

## Conclusion

The major features of the application were tested and verified.
